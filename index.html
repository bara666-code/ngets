LinkTracker

⚙️ Setup sekali saja (wajib agar tracking multi-user jalan)

  1. Buka jsonbin.io/login → daftar gratis (bisa pakai Google)
  2. Setelah masuk, buka API Keys
  3. Salin Master Key (dimulai dengan $2a$... atau $2b$...)
  4. Tempel di bawah → klik Simpan
✓ API Key tersimpan. Sekarang boleh buat link tracking.
File dibuka secara lokal. Disarankan host di https://app.netlify.com/drop atau jalankan python -m http.server 8080 lalu buka http://localhost:8080
